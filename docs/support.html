NordAccess
アプリ紹介 サポート プライバシーポリシー

サポート

本アプリは NordVPN の公式アプリではありません。Linux 向けアクセストークンから WireGuard 設定を生成するユーティリティです。

使い方

  1. NordVPN アカウントで Linux 向けアクセストークン を発行します。
  2. 本アプリにトークンを入力し、必要に応じて国を選択します。
  3. 「プロファイル生成」で WireGuard 設定を作成します。
  4. 推奨サーバー候補から接続先を選び、「ファイル保存」または QR コードを WireGuard アプリで読み取ります。

よくある質問

ログインは必要ですか？

不要です。トークンは都度入力してください。アプリ内にアカウント機能はありません。

VPN 接続は本アプリで行いますか？

いいえ。設定ファイルの生成・表示・保存のみです。接続は WireGuard など別アプリで行ってください。

トークンは開発者に送られますか？

開発者のサーバーには送信されません。プロファイル生成時のみ Nord Security の API（api.nordvpn.com）へ HTTPS で送信されます。

国一覧が読み込めません

ネットワーク環境や API の一時的な障害が考えられます。国を未選択のままプロファイル生成を試してください。

トークンが無効と表示されます

トークンの期限切れ、再発行、入力ミスを確認してください。NordVPN 公式サポートでトークンの状態を確認できます。

API の仕様変更で動かなくなることはありますか？

NordVPN Linux クライアントが利用する非公開 API を利用しているため、将来変更される可能性があります。Issue でご報告ください。
